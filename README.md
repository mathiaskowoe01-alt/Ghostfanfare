# GhostFanfare — Académie Digitale des Fanfaristes & Trompettistes

Plateforme Next.js (App Router + Tailwind CSS v4 + Web Audio API) dédiée aux fanfaristes et trompettistes : portées PDF protégées par filigrane et studio d'écoute audio multi-pupitres (Ensemble, Trompette 1, Trompette 2, Cornet, Trombone, Tuba/Soubassophone).

## Fonctionnalités clés

- **Lecteur Studio Multi-Pupitres Live** : isolation de pupitre en temps réel, vitesse d'étude réglable (`0.6x` → `1.15x`), métronome, boucle, waveform cliquable et mini-lecteur persistant.
- **Portées Protégées** : gravure vectorielle SVG avec curseur synchronisé, filigrane anti-copie et impression PDF une fois débloquée.
- **Catalogue Cuivres Filtrable** : recherche instantanée, filtres par catégorie, tonalité (`Si♭`, `Mi♭`, `Fa`, `Ut`) et niveau.
- **Boutique E-Commerce FCFA / EUR** : panier persistant, favoris, checkout Mobile Money (`MTN MoMo`, `Moov Money`, `Celtiis`) & Carte (`Visa / Mastercard`), et Espace Fanfariste.

## Démarrage local

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).
